# CAA | Exercício Prático (OEA)
O professor da disciplina *CAA* pediu aos seus alunos que o auxiliassem na conceção de um programa em **JAVA** utilizando **Lista Simplesmente Ligada**. O programa deve permitir representar cada aluno. O Aluno é identificado pelo seu **id**, **nome**, **telefone** e **nota** que obteve. A Lista Simplesmente Ligada permitirá representar a turma. 
Pretende-se:
- inserir um aluno
- listar todos os alunos
- pesquisar alunos pelos seguintes critérios (id,nome,telefone)
- mostrar todos os alunos que obtiveram uma determinada nota
- remover alunos por: id, nome, telefone
- impedir a inserção de dados repetidos
